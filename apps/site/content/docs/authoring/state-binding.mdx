---
title: State binding
description: Complete reference for the bind= syntax — every registered element and its data type.
---

Inside a `<Playground>`, the `bind="name:initialValue"` prop is replaced at compile time with generated `useState` hooks and `value`/`onChange` props.

## Registered binding table

| Element                   | Library | Datatype   | `valueProp` | `changeProp`      |
| ------------------------- | ------- | ---------- | ----------- | ----------------- |
| `<input>` / `<textarea>`  | HTML    | `string`   | `value`     | `onChange`        |
| `<input type="checkbox">` | HTML    | `boolean`  | `checked`   | `onChange`        |
| `<input type="number">`   | HTML    | `number`   | `value`     | `onChange`        |
| `<select>`                | HTML    | `string`   | `value`     | `onChange`        |
| `Checkbox` / `Switch`     | shadcn  | `boolean`  | `checked`   | `onCheckedChange` |
| `Slider`                  | shadcn  | `number[]` | `value`     | `onValueChange`   |
| `Select` / `Tabs`         | shadcn  | `string`   | `value`     | `onValueChange`   |
| `Dialog` / `Sheet` / etc. | shadcn  | `boolean`  | `open`      | `onOpenChange`    |
| `Toggle`                  | shadcn  | `boolean`  | `pressed`   | `onPressedChange` |

### Lookup order

1. `name:type` — e.g. `<input type="checkbox">` → `input:checkbox`
2. `name` — e.g. `<Slider>` → `slider`

Unregistered elements get the state variable + `setX` setter but no auto-wired props.

## Custom bindings

Register custom bindings via the `bindings` option on `remarkStateBind`:

```ts
import { remarkStateBind } from "@plannar/core";

const customBindings = {
  "my-component": {
    valueProp: "value",
    changeProp: "onValueChange",
    extract: "e.target.value",
    inject: "[v]", // optional transform
  },
};

remarkStateBind({ bindings: customBindings });
```

Each binding: `valueProp`, `changeProp`, `extract` (expression), and optional `inject` (transform).

## Duplicate names

Duplicate `bind` names within the same Playground are a compile error. Different Playgrounds have independent scopes.
