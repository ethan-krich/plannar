Plannar resolves configuration merged **local > global > defaults**. Both sources are optional.

## Config files

| Source | Path                                            |
| ------ | ----------------------------------------------- |
| Global | `~/.config/plannar/plannar.config.{js,ts,json}` |
| Local  | `./plannar.config.{js,ts,json}` (CWD)           |

JS/TS configs load via `jiti`. JSON is parsed directly.

## Fields

| Field           | Type      | Default              | Description                                     |
| --------------- | --------- | -------------------- | ----------------------------------------------- |
| `plannarFolder` | `string`  | `".plannar"`         | Root folder for plans, components, config       |
| `exportsFolder` | `string`  | `".plannar/exports"` | Output directory for exported HTML              |
| `globalCss`     | `string?` | _none_               | CSS that overrides built-in styles              |
| `cssFilePath`   | `string?` | _none_               | Additional CSS loaded after `globalCss`         |
| `viteConfig`    | `object?` | _none_               | Vite overrides: `{ editor?: {}, exports?: {} }` |

## Derived defaults

`exportsFolder` derives from `plannarFolder` unless set explicitly. If `plannarFolder` is `.my-plans`, `exportsFolder` becomes `.my-plans/exports`.

## Examples

**JSON:**

```json
{
  "plannarFolder": ".plannar",
  "globalCss": ".plannar/theme-overrides.css"
}
```

**TS with Vite overrides:**

```ts
import type { PlannarConfig } from "plannar";

const config: PlannarConfig = {
  viteConfig: {
    editor: { server: { port: 3000 } },
  },
};

export default config;
```
