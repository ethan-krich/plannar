`plannar init` scaffolds everything you need to start writing plans.

## Prerequisites

- **Node.js** 18 or later
- A project directory (any project)

## Quick install

```sh
npx plannar init
```

This creates `.plannar/` in your current directory:

| File                       | Purpose                                |
| -------------------------- | -------------------------------------- |
| `components.json`          | shadcn/ui configuration (Tailwind v4)  |
| `package.json`             | npm package (enables `npx shadcn add`) |
| `tsconfig.json`                | TypeScript config with `@/*` alias     |
| `lib/utils.ts`                 | `cn` utility (clsx + tailwind-merge)  |
| `plans/hello-world.mdx`        | Sample plan with state binding         |
| `components/ui/button.tsx` | Pre-installed Button component         |

Init runs `npx shadcn@latest add button` so the sample plan works immediately. Config is not scaffolded — create a `plannar.config.{js,ts,json}` at your project root to customize.

## Adding components

```sh
npx shadcn@latest add card tabs accordion slider
```

Components are imported with `@/components/ui/...` alias and work inside Playground blocks.
