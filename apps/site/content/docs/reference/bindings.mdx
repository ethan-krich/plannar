title: Bind directives

The `bind="name:initial"` prop, when used inside a `<Playground>`, is replaced at compile time with generated React state hooks and auto-wired value/change props.

## Registered binding table

| Element                   | Library | Datatype   | `valueProp` | `changeProp`      | Extract                  |
| ------------------------- | ------- | ---------- | ----------- | ----------------- | ------------------------ |
| `<input>` / `<textarea>`  | HTML    | `string`   | `value`     | `onChange`        | `e.target.value`         |
| `<input type="checkbox">` | HTML    | `boolean`  | `checked`   | `onChange`        | `e.target.checked`       |
| `<input type="number">`   | HTML    | `number`   | `value`     | `onChange`        | `e.target.valueAsNumber` |
| `<select>`                | HTML    | `string`   | `value`     | `onChange`        | `e.target.value`         |
| `Checkbox` / `Switch`     | shadcn  | `boolean`  | `checked`   | `onCheckedChange` | `e`                      |
| `Slider`                  | shadcn  | `number[]` | `value`     | `onValueChange`   | `e[0]`                   |
| `Select` / `Tabs`         | shadcn  | `string`   | `value`     | `onValueChange`   | `e`                      |
| `Dialog` / `Sheet` etc.   | shadcn  | `boolean`  | `open`      | `onOpenChange`    | `e`                      |
| `Toggle`                  | shadcn  | `boolean`  | `pressed`   | `onPressedChange` | `e`                      |

## Lookup order

1. `name:type` — e.g. `<input type="checkbox">` → `input:checkbox`
2. `name` — e.g. `<Slider>` → `slider`

## BindingMeta type

```ts
interface BindingMeta {
  valueProp: string; // e.g. "value", "checked"
  changeProp: string; // e.g. "onChange", "onValueChange"
  extract: string; // e.g. "e.target.value", "e[0]"
  inject?: string; // optional transform, "v" holds the value
}
```

## Custom binding registration

```ts
import { remarkStateBind } from "@plannar/core";

const custom = {
  "my-slider": {
    valueProp: "value",
    changeProp: "onSlide",
    extract: "e.detail.value",
  },
};

remarkStateBind({ bindings: custom });
```

## Duplicate names

Duplicate `bind` names within the same `<Playground>` produce a compile error. Different Playgrounds have independent scopes.
