title: plannar init
description: Scaffold .plannar/ with shadcn/ui components, sample plans, and config.
---

Scaffolds `.plannar/` in the current directory.

## Usage

```sh
npx plannar init
```

## What it creates

| File                             | Purpose                                |
| -------------------------------- | -------------------------------------- |
| `components.json`                | shadcn/ui configuration                |
| `package.json`                   | npm package (enables `npx shadcn add`) |
| `tsconfig.json`                | TypeScript config with `@/*` alias     |
| `lib/utils.ts`                 | `cn` utility (clsx + tailwind-merge)  |
| `node_modules/.plannar-junk.css` | Dummy CSS target for shadcn            |
| `plans/hello-world.mdx`          | Sample plan with state binding         |
| `components/ui/button.tsx`       | Pre-installed Button component         |

After scaffolding, runs `npx shadcn@latest add button` so the sample plan works immediately. Config is not scaffolded — create `plannar.config.{js,ts,json}` at your project root to customize.

## After init

```sh
plannar editor    # Start preview server
plannar status    # Check if running
plannar export    # Export as HTML
```
