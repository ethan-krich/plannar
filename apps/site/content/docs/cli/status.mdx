---
title: plannar status
description: Check if the editor is running, on which port, and whether it belongs to the current project.
---

Reports the editor's status, URL, and project match. Lists all running editors found in the scanned port range.

## Usage

```sh
plannar status
```

## Flags

| Flag     | Type     | Default     | Description   |
| -------- | -------- | ----------- | ------------- |
| `--port` | `number` | `5173`      | Port to check |
| `--host` | `string` | `localhost` | Host to check |

## Behavior

- Scans all ports from the given port across the next 10 ports
- Verifies each responder is a plannar editor (checks for `plannar-editor` meta tag)
- Extracts each running editor's plannar root from the `plannar-root` meta tag
- Compares against the current project's resolved plannar folder
- Reads `viteConfig.editor.server` from JS/TS configs

## Output

When an editor is running for this project:

```
✓ Editor running for this project at http://localhost:5173
```

When an editor is running for this project and others exist:

```
✓ Editor running for this project at http://localhost:5173

Other projects:
  http://localhost:5174 → /other-project/.plannar
```

When editors are running but none for this project:

```
✗ No editor running for this project

Other projects:
  http://localhost:5173 → /other-project/.plannar
```

When no editor is running at all:

```
✗ No editors running
```
