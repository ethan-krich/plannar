# Plannar Editor

A comprehensive MDX renderer with state binding playgrounds.

## Features

- **GitHub Flavored Markdown** via `remark-gfm`
- **Syntax highlighting** via `rehype-pretty-code`
- **Auto-linked headings** via `rehype-autolink-headings`
- **shadcn/ui** components in playgrounds

### Code Example

```ts
function hello(name: string): string {
  return `Hello, ${name}!`;
}
```

## Playground

`<Input>` with `bind="text:'Hello world'"` auto-wires `value` + `onChange`:

<Playground>
  <Input bind="text:'Hello world'" placeholder="Type something..." />
  <p>You typed: {text}</p>
</Playground>

`<Button>` with `bind="count:0"` creates state only — you wire `onClick` manually:

<Playground>
  <Button bind="count:0" onClick={() => setCount(count + 1)} variant="outline">
    Clicked {count} times
  </Button>
</Playground>

`<Checkbox>` with `bind="checked:true"` auto-wires `checked` + `onCheckedChange`:

<Playground>
  <label>
    <Checkbox bind="checked:true" /> Toggle me ({String(checked)})
  </label>
</Playground>

Number `<Input>` with `bind="amount:10"` auto-wires `value` + `onChange`:

<Playground>
  <Input type="number" bind="amount:10" />
  <p>Amount: {amount}</p>
</Playground>
